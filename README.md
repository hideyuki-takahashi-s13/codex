# Neon Dodge Arena

モダンなグラスモーフィズムUIで遊べる、ブラウザ用ミニゲームです。プレイヤーを操作して迫ってくるネオン障害物を避け続け、スコアを伸ばします。

## Features
- 🎮 キーボード操作（矢印キー / WASD）
- ✨ グロー演出を使ったモダンUI
- 📈 時間経過で難易度上昇
- 🏆 ローカルストレージにハイスコア保存

## Run
以下のどちらかで起動できます。

### 1) Pythonでローカルサーバ起動
```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開いてください。

### 2) 直接開く
`index.html` をブラウザで開いても動作します。
